# Linux Temelleri

## Terminal Komutları (ls, cd, grep, mkdir, chmod, top)
Linux'ta terminal, komutlarla işletim sistemini yönetmeyi sağlar.
- ls dosyaları listeler
- cd dizin değiştirir
- grep metin arar
-mkdir klasör oluşturur
- chmod izinleri değiştirir 
- top çalışan işlemleri gösterir.


## Paket Yönetimi (apt / pacman / dnf)
Yazılımları yüklemek, güncellemek ve kaldırmak için kullanılır. apt Debian/Ubuntu, pacman Arch Linux, dnf Fedora sistemlerinde yaygın.


## File Permissions (Dosya İzinleri)
Dosyaların kimler tarafından okunabileceğini, değiştirilebileceğini ve çalıştırılabileceğini belirler. Temel izinler r (read), w (write) ve x (execute) şeklindedir.


## Services (systemctl)
Linux'ta sistem servislerini yönetmek için kullanılır. systemctl start servisi başlatır, systemctl stop durdurur ve systemctl status çalışma durumunu gösterir.
