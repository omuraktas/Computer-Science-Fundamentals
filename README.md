# Computer Science Fundamentals

Bu repo, bilgisayar mühendisliği ve yazılım öğrenme sürecimde hazırladığım kısa, anlaşılır ve temel kavramlara odaklanan notları içerir.

## İçerikler

- Bilgisayar Bileşenleri
- İşletim Sistemi Temelleri
- Dosya Sistemleri ve Depolama Mantığı
- Linux Temelleri
- Ağ Temelleri
- Algoritma ve Veri Yapıları
- API Mantığı (REST & JSON)
- Veritabanı Mantığı (SQL)
- Yazılım Mimarisi Temelleri

## Amaç

Bilgisayar biliminin temel kavramlarını öğrenmek, teknik bilgimi geliştirmek ve öğrendiklerimi düzenli bir şekilde belgelemek.
