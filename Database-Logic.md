# Veritabanı Mantığı (SQL Temelleri)

## Relational Database (İlişkisel Veritabanı)
Verileri tablolar halinde saklayan ve tablolar arasında ilişkiler kurmayı sağlayan veritabanı türüdür.
- MySQL
- PostgreSQL 
- SQL Server örnek olarak verilebilir.


## Primary Key – Foreign Key
Primary Key, tablodaki her kaydı benzersiz şekilde tanımlar. 
Foreign Key ise tablolar arasında ilişki kurmak için başka bir tablonun anahtarına referans verir.


## SELECT – JOIN – GROUP BY
SQL'de verileri sorgulamak ve düzenlemek için kullanılır.
- SELECT: Tablodan veri getirir.
- JOIN: İlişkili tabloların verilerini birleştirir.
- GROUP BY: Verileri belirli alanlara göre gruplandırır; genellikle COUNT, SUM ve AVG gibi fonksiyonlarla kullanılır.


## Index (İndeks)
Veritabanında kayıtların daha hızlı bulunmasını sağlayan yapıdır. 
Arama işlemlerini hızlandırabilir ancak ek depolama alanı kullanır ve veri ekleme, silme veya güncelleme işlemlerini yavaşlatabilir.
